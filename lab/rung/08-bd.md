# Rung 8: a seat files a bd issue and you close it

Demo: a seat calls bd on its own, and you close what it filed.

You: ask the agent to apply workloads/bd-ticker/manifest.toml with `marvel work`, then show the issue labelled `lab-ticker-note` with `bd list --label lab-ticker-note`. Ask it to close that issue. Run `just lab check 08`.

## Tools

- marvel and bd inside this lab, from rungs 0a and 0f. The seat must run in a directory that belongs to the lab's bd workspace.
- The seat only creates and lists. The issue carries the labels `lab` and `lab-ticker-note`, and the check finds it by the second one.

## Expected prompts

- `marvel work` asks. Answer yes.
- `bd list` and `bd show` do not ask.
- `bd close` asks. Answer yes; the issue is a throwaway.
